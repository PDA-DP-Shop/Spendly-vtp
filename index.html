GhostLink V1

A two-phone screen-to-camera experiment. It transmits short text through changing screen brightness—no QR code.

Sender screen

Open on the sending phone. Keep the page visible and screen brightness high. Start with strong contrast and 700 ms bits.

Ready to transmit
Press Start transmission
IDLE

Repeats the same packet until stopped.

Receiver camera

Open on the receiving phone. Allow camera permission, point at the sender screen from 20–50 cm, then tap Listen.

Test steps

1. Upload index.html to GitHub. 2. Enable GitHub Pages (Settings → Pages → main → root). 3. Open the HTTPS URL on two phones. 4. Sender: Start. Receiver: Enable camera → Listen.

V1 is an experimental prototype and may not decode reliably on all phone/camera combinations. It is not invisible yet and has no encryption, sender authentication, replay protection, or payment integration. Do not use financial or sensitive data.

Local browser demo · no data upload · camera access requires HTTPS or localhost.
