What is encoded

A fixed compact binary transaction packet is mapped to 4 concentric pulse rings. Each ring has 64 angular symbols; every symbol carries 2 bits by radial state. The packet contains VTP header, amount, currency, merchant/invoice identifiers, timestamp, nonce, CRC-32 and a demo authentication tag. The visible pattern contains no readable JSON.
Research prototype. Similar circular/radial optical codes exist in prior art; this does not establish global novelty. Camera reliability must be measured on target devices rather than guaranteed.
