After Start the scanner continuously analyzes frames. There is no Capture button. For the first test, display the pulse on another screen, fill most of the camera view, and keep it roughly front-facing.

Protocol test gates

Gate 1: binary encode/decode 1000×. Gate 2: deterministic image sampling with blur/noise/scale tests. Gate 3: live camera test on the target phone. The software can be made deterministic and testable; no honest implementation can guarantee every phone, distance, angle and lighting condition.
The visual is intentionally not a QR/Data Matrix square grid. Circular/radial optical codes have prior art, so this is presented as a Spendly research prototype, not a claim of global novelty.
